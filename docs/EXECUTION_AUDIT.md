## Executive summary

The repository is already a substantial Dera Darko Trade commerce application, not an empty screenshot-to-site starter. Preserve its React 19 / TypeScript / Vite / TanStack Start architecture, existing commerce services, authentication, checkout, pricing, security controls and Cloudflare deployment approach.

The largest unfinished area is the AI Product Image Studio. Domain types, product-specific prompts, an OpenAI-compatible provider adapter, an orchestration service, a SQL migration and unit tests exist. The generation service currently keeps jobs in process memory, is not wired into the admin API/dashboard, and has no production R2 image-storage adapter. Live generation is blocked until the server-side IMAGE_API_KEY is configured.

## AI image generation gaps

1. Image provider configuration is not part of the API Env type / WorkerEnv wiring.
2. The image-generation service stores its job map in memory; jobs do not survive Worker restarts.
3. There is no R2 adapter implementing the ImageStorage interface for generated bytes.
4. Generation is not connected to product-specific admin API routes.
5. The admin dashboard has no AI Product Image Studio tab.
6. There is no durable batch queue, progress endpoint, cancellation/resume mechanism or persisted cost/usage ledger.
7. Generated image records need to be persisted in the existing product media structure with provider, model, prompt, angle, provenance and approval state.
8. Existing product media code still accepts a Canva design ID. That field and validation are legacy and should be deprecated safely, not used by the new workflow.

## Required credentials / external setup

- IMAGE_API_KEY: server-side key for the selected image-generation provider.
- IMAGE_API_BASE_URL and IMAGE_MODEL: optional provider configuration.
- Cloudflare D1 database binding DB and deployed migration state.
- Cloudflare R2 bucket binding MEDIA.
- SESSION_SECRET, SITE_ORIGIN and ADMIN_PORTAL_PATH.
- Payment and email credentials are separate existing deployment requirements and are not required to build the image studio.
- Real supplier/manufacturer product photographs, verified specifications and owner-approved prices are catalogue inputs, not secrets.

Implementation is isolated on feat/dera-ai-product-image-studio. Do not force-push, rewrite published history, or commit secrets. Do not run a bulk generation job, publish prices/products, or deploy production without the relevant owner approval and verified credentials.
