# AI Product Image Studio — architecture (no Canva)

## Policy
- **No Canva** dependency for product imagery.
- AI images may be shown as ordinary product photos (owner decision 2026-10-31). Do **not** show customer-facing “AI / illustrative” labels.
- Track `source: ai_generated` internally so real supplier photos can replace them later.
- Never invent prices, stock, medical claims, logos, or certifications.
- Skip AI generation for: vehicles, medical equipment, teas/supplements, building materials.

## Modules
| Path | Role |
|------|------|
| `src/lib/domain/image-generation.ts` | Types, statuses, safety skip rules |
| `src/server/images/prompt.ts` | Category-specific commercial photography prompts |
| `src/server/images/provider.ts` | Provider interface + OpenAI-compatible adapter |
| `src/server/images/service.ts` | Orchestration: prompt → generate → store → job record |
| `db/migrations/0002_image_generation.sql` | `product_images` metadata + `image_generation_jobs` |
| `src/test/image-generation.test.ts` | Unit tests (fail-closed, safety, happy path with fake provider) |

## Credentials
```
wrangler secret put IMAGE_API_KEY
# optional:
# IMAGE_API_BASE_URL=https://api.openai.com/v1
# IMAGE_MODEL=gpt-image-1
```
Without `IMAGE_API_KEY`, generation jobs fail closed with a clear error. No fake “success”.

## Storage
Generated bytes must be written to permanent storage (Cloudflare R2 `MEDIA` binding preferred — same path as owner photo uploads). Temporary provider URLs are not used as product images.

## Dual currency
Already implemented (`src/lib/domain/money.ts`, exchange rate settings, dual display). Products stay unpublished until a price is approved. Default rate in `.env.example`: 11.47 GHS per USD (owner-set).
